The task inbox — open work routed to identities (assigned →, push) or to a role's pull-queue (queued →, claimed via ClaimTask). An assignee's available/unavailable chip is the routing gate (SetAvailability). A stuck · unrouted task is an open role-queued task past its own expiry with no claim (FR29) — it sorts to the top; the operator is its remediation. "Complete →" jumps to Submit Op with that operation pre-selected.

The Personal Lens subscriber fleet — every device registered through personal.register, with its Interest Set and its position in the SYNC stream. A device is gapped when the stream's retention floor has overtaken the point it consumed through: those deltas aged out, so a warm resume would silently miss them and the device needs a cold personal.hydrate. Gap state comes from each device's own JetStream ack floor; a device with no consumer has no comparable position, so its gap state reads unknown rather than healthy. This is who is registered, not who is connected.

The Chronicler's durable Loom-flow history — every instance's lifecycle (pattern, timestamps, failure reason), reconstructed from the loom.* event stream, grouped by pattern and ordered worst-first. A still-running row is cross-referenced against Loom's own instance state: live (the engine is running it), history stale (the engine considers it finished — the terminal event never reached this projection), or orphaned (the engine has no record of it at all). Neither of the last two is a leak, and neither is a stuck flow; both are the history disagreeing with the engine. Read-only — Loom exposes no per-instance redrive, so there is no control-plane op from here.
